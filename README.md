# КомфортМонтаж71

Сайт компании «КомфортМонтаж71» — производство металлоконструкций в собственном цеху, строительство и монтаж (Тула и Тульская область).

## Структура

```
index.html        — одностраничный сайт
css/styles.css    — стили (тёмная «индустриальная» тема, оранжевый акцент)
js/main.js        — меню, анимации, счётчики, фильтр объектов, форма заявки
assets/favicon.svg
```

Сайт статический, без сборки: достаточно открыть `index.html` или разместить файлы на любом хостинге (GitHub Pages, Netlify, обычный веб-сервер).

```bash
python3 -m http.server 8000   # http://localhost:8000
```

## Что нужно заменить реальными данными

- **Контакты** — телефон `+7 (4872) 00-00-00`, e-mail `info@komfortmontazh71.ru`, адрес и режим работы (`index.html`, секции шапки и `#contacts`; e-mail также в `js/main.js`).
- **Цифры** в блоке статистики (лет на рынке, объекты, тонны, гарантия) — сейчас примерные.
- **Объекты в портфолио** — названия и описания в секции `#projects`. Фоны-заглушки задаются классами `.project__img--1…5` в `css/styles.css`; замените на фото: `background: url(../assets/projects/1.jpg) center / cover;`.
- **Плитки цеха** (`.tile--a/b/d`) — аналогично можно поставить фото производства.

## Форма заявки

По умолчанию форма открывает почтовый клиент с заполненным письмом. Чтобы заявки уходили на сервер (CRM, Telegram-бот, Formspree и т. п.), укажите URL в константе `FORM_ENDPOINT` в `js/main.js` — данные отправятся POST-запросом в JSON: `name`, `phone`, `service`, `message`.
